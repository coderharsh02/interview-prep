## 🧩 **What is .NET Core?**

* A **cross-platform**, **free**, **open-source**, **general-purpose** development platform.
* Maintained by **Microsoft** and available on **GitHub**.

### 🔄 Difference Between .NET Core and .NET Framework

| Feature            | .NET Core                                    | .NET Framework           |
| ------------------ | -------------------------------------------- | ------------------------ |
| Platform Support   | Cross-platform (Windows, macOS, Linux)       | Windows-only             |
| Package Management | Modular (install only needed NuGet packages) | Installs all packages    |
| Performance        | Lightweight, better performance              | Heavier memory footprint |

---

## 🌟 **Features of .NET Core**

* Open-source and available on GitHub.
* Supports **cross-platform** development.
* Can build: Web, Mobile, Desktop, IoT, ML, Microservices, Cloud, Games.
* Multi-language support: **C#**, **F#**, **VB.NET**.
* IDEs: Visual Studio, VS Code, Sublime, Vim, etc.
* Uses **NuGet packages** (modular approach).
* Includes **Command Line Interface (CLI)** for CI/CD and development.

---

## 🧱 **Main Components of .NET Core**

1. **CLI Tool** – For command line development and deployment.
2. **Roslyn** – Compiler for C# and VB.NET.
3. **CoreFX** – Framework class libraries.
4. **CoreCLR** – Common Language Runtime with JIT (Just-In-Time) compilation.

---

## 🌐 **What is ASP.NET Core?**

* Modern version of ASP.NET, targeted to run on .NET Core.
* Used to build **cloud-based apps** like:

  * Web apps
  * IoT apps
  * Mobile backends
* **Open-source**, **cross-platform**, **high-performance**.

---

## ⚙️ **Features of ASP.NET Core**

* Cross-platform hosting: Windows, Linux, macOS.
* Default web server: **Kestrel** (also supports IIS, Nginx, Docker).
* Frequent updates due to open-source nature.
* Seamless support for **Azure Cloud**.
* Built-in support for **Dependency Injection** (will be covered in-depth).
* Massive community and active contributors on GitHub.
