### 🔹 **Overview**

* **Kestrel** is the **default** server used when running ASP.NET Core applications.
* The entry point of any ASP.NET Core app is `Program.cs`.
* The call to `CreateBuilder(args)` in `Program.cs` sets up the default **Kestrel server**.

---

### 🔹 **What is `launchSettings.json`?**

Located under the **`Properties`** folder, it defines how the application should be launched during development.

#### 🧩 Structure:

```json
{
  "iisSettings": {
    "windowsAuthentication": false,
    "anonymousAuthentication": true,
    "iisExpress": {
      "applicationUrl": "http://localhost:55675",
      "sslPort": 0
    }
  },
  "profiles": {
    "Kestrel": {
      "commandName": "Project",
      "dotnetRunMessages": true,
      "launchBrowser": true,
      "applicationUrl": "http://localhost:4200",
      "environmentVariables": {
        "ASPNETCORE_ENVIRONMENT": "Development"
      }
    },
    "IIS Express": {
      "commandName": "IISExpress",
      "launchBrowser": true,
      "environmentVariables": {
        "ASPNETCORE_ENVIRONMENT": "Development"
      }
    }
  }
}
```

---

### 🔹 **Key Terms**

| Setting                | Meaning                                                                                           |
| ---------------------- | ------------------------------------------------------------------------------------------------- |
| `commandName`          | Tells which server to use: <br>• `"Project"` = **Kestrel** <br>• `"IISExpress"` = **IIS Express** |
| `applicationUrl`       | URL and port where the app runs                                                                   |
| `launchBrowser`        | If `true`, browser opens automatically on run                                                     |
| `dotnetRunMessages`    | If `true`, shows CLI output when running via terminal                                             |
| `environmentVariables` | Sets environment (Development, Production, etc.)                                                  |

---

### 🔹 **Server Options in Development**

1. **Kestrel Server**

   * Default for ASP.NET Core.
   * Profile `"commandName": "Project"`.
   * Cross-platform.
   * Can customize port (`applicationUrl`) or profile name (e.g., "HTTP" → "Kestrel").

2. **IIS Express**

   * Only available on Windows.
   * Lightweight version of full IIS.
   * Profile `"commandName": "IISExpress"`.
   * Port and settings found under `iisSettings`.

---

### 🔹 **Running the Application**

* The **Run button dropdown** in Visual Studio lets you choose the profile:

  * `"Kestrel"` or `"HTTP"` → uses **Kestrel**
  * `"IIS Express"` → uses **IIS Express**

* The **port number** defined in `applicationUrl` determines where the app will be hosted (e.g., `http://localhost:4200`).

> 🛑 Port number should be **between 1024 and 65535**.

---

### 🔹 **Customization Tips**

* ✅ Change port: edit `applicationUrl`
* ✅ Change profile name: e.g., rename `"HTTP"` to `"Kestrel"`
* ❌ Don’t change `commandName` values—they must be `"Project"` or `"IISExpress"` respectively.

---

### 🔚 Summary

* `launchSettings.json` helps control **which server to use**, **what URL to host on**, and **how to behave during development**.
* **Kestrel** is the modern, default server for ASP.NET Core.
* **IIS Express** provides additional Windows-only features, useful for simulating production behavior on local Windows machines.
