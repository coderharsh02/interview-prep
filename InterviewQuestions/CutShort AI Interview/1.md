#### 1. **SQL Query Analysis**

> **Question:**
> Here's a SQL query for you to analyze:

```sql
SELECT e.name, d.department_name  
FROM employees e  
JOIN departments d ON e.department_id = d.id  
WHERE e.salary > 50000;
```

Can you identify any potential performance bottlenecks in this query and suggest how you would optimize it?

---

#### 2. **JavaScript Fetch API – Error Handling**

> **Question:**
> Here's a JavaScript code snippet that fetches data from a REST API:

```javascript
fetch('https://api.example.com/data')
    .then(response => response.json())
    .then(data => { 
        console.log(data);
    })
    .catch(error => { 
        console.log('Error:', error);
    });
```

Can you identify any potential issues in this code and suggest improvements related to error handling, performance, and reliability?
